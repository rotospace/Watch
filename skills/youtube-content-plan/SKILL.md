# YouTube Content Plan

Plans a batch of videos in one pass instead of one video at a time, so
later videos in the slate can reference earlier ones without
re-explaining the series, and so every video is assigned a job in the
funnel before it's filmed rather than after it flops.

## Default niche for this channel

Unless told otherwise, plan for **AI agents and competitive
intelligence for local service businesses** (flooring, landscaping,
roofing, HVAC, and similar trades) -- the same audience front9 is
already selling to. This channel exists to feed that business, not to
chase ad RPM on its own, so weight the slate toward formats that
produce pilot leads and case-study proof over pure reach.

## The eight formats and what each is actually for

1. **Build-in-N-minutes.** A concrete build, start to finish. Pure
   top-of-funnel reach -- this is how strangers find the channel.
2. **Comparison.** Weighing tools or approaches against each other.
   Slightly better at converting viewers into subscribers than format 1,
   because the viewer is already evaluating something.
3. **Build-log / case study.** Document an actual project as it
   happens -- for this channel, that's the epoxy-company pilot and
   whatever comes after it. Smaller audience, much higher buyer intent.
   This is the format that should carry the most weight in the slate.
4. **Conversation / interview.** A real customer or an industry voice.
   Best format for list growth -- pair it with a lead-magnet CTA.
5. **Best-practice critique.** "Here's what most [trade] owners get
   wrong about X." Reliable watch time, good mid-funnel format.
6. **Commentary.** An opinion on where the industry/local competition
   dynamics are heading. Builds the kind of audience that later
   supports a membership or community, if that's ever added.
7. **Live process.** Run the actual agent live, or narrate a real
   report being generated in real time. Highest-trust format of the
   eight, and the one most likely to turn a viewer into a pilot lead
   directly -- treat this as a close second to the case-study format.
8. **Shorts.** Cut from the other seven, not filmed separately. Pure
   reach and a feeder into the rest -- no format of its own to plan.

For this channel, bias a 10-video slate toward formats 3, 5, and 7,
using 1 and 2 for reach and 4 for list growth. Format 8 isn't part of
the 10 -- it's produced from whichever of the ten gets cut into clips.

## What to produce

1. **A 10-video slate** spanning the formats above, each video given a
   one-line premise and which of the eight formats it uses.
2. **A funnel note per video** -- what it's actually for (reach,
   subscribe, list-growth, pilot lead, case-study proof) and what its
   CTA should point to. A case-study or live-process video should
   generally point at a call/demo, not a generic subscribe ask.
3. **A full script for video 1 only**, broken into scenes, each scene
   carrying: a timestamp, what's on screen (including any on-screen
   text cues), the narrator line, and the CTA if that scene has one.
   Close with three distinct thumbnail concepts. Output the script as
   JSON keyed by scene so it can feed directly into a metadata- or
   Shorts-generation step later without reformatting.

## Using this skill

1. Confirm the niche -- use the front9 default above unless the user
   names a different one.
2. Produce the 10-video slate with formats and funnel notes first, as
   a quick scan the user can approve or reshuffle before any scripting
   effort goes in.
3. Only after the slate is approved (or on request), write the full
   scene-by-scene script for video 1.
4. Flag if the slate is drifting toward pure-reach formats (1, 2, 8)
   at the expense of 3, 5, and 7 -- that's optimizing for views on a
   channel that's supposed to be optimizing for pilot leads.
