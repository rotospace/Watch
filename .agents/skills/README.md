# Marketing Skills

Marketing skills for Claude Code and AI agents — CRO, copywriting, SEO,
analytics, growth engineering, cold email, positioning, and more.

Vendored from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills)
(MIT licensed, see `LICENSE`). Each subdirectory is a self-contained skill
with a `SKILL.md` describing when and how to use it.

For this project (Local Prospect Outreach), the most relevant skills are:
`cold-email`, `copywriting`, `copy-editing`, `prospecting`, `cro`,
`marketing-psychology`, `emails`, and `sales-enablement`.
